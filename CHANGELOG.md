# Changelog

## v1.0.0 (2026-10-18)

First release.

- Load single presets, backup folders and allBanks files; validate all check values
- Slot grid with drag-to-move/swap, rename, bank/slot change, export as `.syx`, ZIP or combined file
- Full preset editing: block parameters per channel, block types, scene names, per-scene channel and on/off, slot swapping, Series/Parallel routing, 4CM mode, scene MIDI, preset tempo
- Mix Overview and parallel-block display like VP4-Edit
- System settings editor for backup system files
- Edited presets are re-compressed exactly like Fractal's own files; all check values are recomputed
- Parameter names, ranges and value lists for VP4 firmware 4.04 built in
